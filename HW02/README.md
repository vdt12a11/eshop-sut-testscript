# HW02 — Domain Testing và Boundary Value Analysis

## Tổng kết kiểm thử

Thống kê theo TC duy nhất; TC dùng chung Domain Testing/BVA chỉ tính một lần. Trạng thái theo lần chạy gần nhất của bộ thiết kế hiện tại. Chưa kế thừa Pass cũ của TC01 vì phạm vi kiểm tra đã mở rộng.

Not Run gồm chưa chạy hoặc chưa kết luận do thiếu oracle/giới hạn nhập liệu. Với trường hợp đã quan sát một phần, Actual ghi rõ phần đã quan sát; không tính thành Pass hay Executed. Trạng thái Jest phản ánh việc kịch bản có hoàn tất, còn tổng kết nghiệp vụ lấy từ results.json. Các lần chạy trước được giữ trong `jest-tests/runs/`.
